# Stored XSS

- `XssInject.tsx`: уязвимый HTML-рендер пользовательского комментария.
- `FixedXssInject.tsx`: исправленный вывод того же комментария как текста.
- `CommentsBoard.tsx`: общий список и прямой выбор компонента по режиму.
- `CommentForm.tsx`: общая форма отправки комментария.
- `XssInject.test.tsx`, `CommentsBoard.test.tsx`: тесты пары и выбора режима.

Демо: `/site/comments`. Сначала показываем уязвимость, затем в том же демо
переключаем на «Исправлено». Сохранённый комментарий остаётся тем же.
Слайд с исходниками: `/talk/xss/1`.
