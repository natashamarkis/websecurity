# Уязвимые npm-зависимости

Демо: `/site/product`. Слайды: `/talk/dependencies/0` (суть), `/1` (audit и
обновление), `/2` (код библиотеки), `/3` (демо).

## Файлы

- `library/ProductDescription.tsx`: версия 1.0.0, передаёт описание в `dangerouslySetInnerHTML`.
- `library/FixedProductDescription.tsx`: версия 1.0.1, выводит обычный текст через React.
- `ProductPreview.tsx`: выбирает компонент библиотеки через `vulnerable ? ... : ...`.
- `DependencyDemo.tsx`: общая форма, версия библиотеки, карточка товара и сброс.
- `fixtures.ts`: исходное описание и локальный payload с alert.
- `ProductPreview.test.tsx`: контракт двух реализаций; `e2e/dependencies.spec.ts`: выполнение в браузере.

`demo-description` — вымышленная локальная учебная библиотека, не опубликованный
npm-пакет и не воспроизведение известного CVE. Обе реализации находятся в исходниках;
переключатель не запускает установку пакетов. Форма-потребитель остаётся одинаковой.
Исправление сохраняет контракт обычного текста, но не поддерживает rich HTML.

Ввод хранится только в состоянии React, сохраняется при переключении режима и
сбрасывается общей кнопкой либо перезагрузкой страницы. `pnpm audit` не найдёт эту
учебную ошибку: локальная библиотека не имеет записи в базе advisory.
